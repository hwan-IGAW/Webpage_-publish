# 모바일인덱스 MCP 사용 현황 종합 분석 보고서

**분석 기간:** 2026년 5월 21일 ~ 6월 26일  
**데이터 소스:** Google Analytics 4, 디파이너리(애드브릭스), 내부 크레딧 사용 로그, 아웃바운드 미팅 기록, Meta 광고 성과 리포트  
**작성일:** 2026년 6월 26일  
**비고:** digitalminty(자회사) 제외 기준

## 1. Executive Summary

모바일인덱스 MCP는 현재 **소프트 런칭 단계**로, MCP 직접 연동만 가능한 상태에서 의도적으로 소규모 매체비(약 130만원)로 운영 중이다. 목적은 실 전환보다 **"모바일인덱스가 AI/MCP 변화를 리드하고 있다"는 시장 포지셔닝 메시지 전달.**

23일간 방문자 11,522명, 페이지뷰 49,618회를 기록했고, **MCP 키 발급 101명**(중복 제거) 중 **실제 사용자 45명, 미사용 56명(55.4%)**이다. 뉴스레터가 발급의 50.5%를 기여하며 핵심 전환 채널로 확인되었다.

1~2주 내 GPT 앱 및 클로드 커넥터 승인·등록이 완료되면 **그랜드 오픈 + 매체비 확대** 예정이며, 기술 허들 해소로 퍼널 전환율의 구조적 변화가 예상된다.

## 2. 현재 전략적 위치

### 현재 상태: 소프트 런칭

| 항목 | 현재 | 그랜드 오픈 후 (예정) |
|------|------|------|
| 연동 방식 | MCP 직접 연동만 (터미널 필요) | **GPT 앱 + 클로드 커넥터** (원클릭) |
| 매체비 규모 | 약 130만원 (인지 목적) | 확대 예정 |
| 마케팅 목적 | 시장 포지셔닝, 리더십 메시지 | 실 전환 + 사용자 확보 |
| 타겟 | 얼리어답터, 기존 유료 고객 | 일반 마케터/기획자까지 확대 가능 |
| 캠페인 KPI | CTR, 랜딩 유입당 비용 | 전환·활성 사용자 수 |

### 소프트 런칭의 전략적 의도
- MCP 직접 연동은 진입장벽이 높다는 것을 인지한 상태
- 현재 광고는 전환 목적이 아닌 **"모바일인덱스가 변화를 리드하고 있다"는 메시지**를 시장 주시자에게 전달하기 위함
- 따라서 현재의 높은 이탈률과 낮은 전환은 예상된 결과이며, 이 단계의 KPI는 CTR과 유입당 비용

## 3. 전제 조건 및 맥락

### 크레딧 체계
| 등급 | 일 크레딧 | 설명 |
|------|----------|------|
| BASIC | 30/일 | 모바일인덱스 무료 회원 (기존 or 신규) |
| ESSENTIAL | 200/일 | 기존 모바일인덱스 유료 고객 |
| PREMIUM | 500/일 | 기존 모바일인덱스 유료 고객 상위 등급 |

### 제품 특성
- 모바일인덱스는 **매일 쓰는 서비스가 아님** — 보고 시기, 사업계획 수립 시기 등에 몰아 쓰는 패턴이 정상
- 여러 앱을 봐야 하는 곳(미디어렙/VC 등)은 상대적으로 자주, 자사 앱만 보는 일반 광고주는 필요 시에만 사용
- **활성도 판단 기준:** 사용 일수 + 사용한 날의 의미 있는 활동 여부

### 기술 허들 (현재 — 그랜드 오픈 시 해소 예정)
- MCP 사용을 위해 터미널 조작 또는 MCP 클라이언트 설치 필요
- 아웃바운드 미팅에서도 MCP 연동 경험자가 거의 전무
- **GPT 앱 / 클로드 커넥터 등록 시 이 허들 대폭 해소 예상**

1. **"긍정 반응 ≠ 즉시 사용"** — 연동 과정 자체가 허들. GPT 앱/커넥터 출시 시 해소 예상.
2. **클로드 종속 문제** — 이노션, 한국언론진흥재단. **GPT 앱 등록으로 해결 예정.**
3. **보안/승인 프로세스** — 대기업은 외부 API 연결에 사내 승인 필요 (구조적, 해소 어려움)
4. **MCP 연동 경험 전무가 보편적** — GPT 앱/커넥터로 "연동" 개념 자체가 불필요해지면 해결
5. **"모바일인덱스 내 AI 에이전트" 수요** — 삼성카드 명시적 요청. 별도 검토 필요.

## 13. 결론

### 소프트 런칭 기간 평가

모바일인덱스 MCP 소프트 런칭은 **본래 목적(시장 포지셔닝 + 얼리어답터 검증)에 부합하는 성과**를 냈다:

- 130만원 소규모 예산으로 25.5만 노출, 11,522명 유입
- 발급 101명, 실 사용 45명, Heavy 11명 확보
- 유료 고객 사용률 62~67%로 제품 가치 검증
- 기존 고객 미팅에서 제품-시장 적합성 확인
- 이탈 지점과 허들을 명확히 파악하여 그랜드 오픈 전략 수립 가능

### 그랜드 오픈의 핵심 변수

**GPT 앱 / 클로드 커넥터 출시가 게임 체인저.**

현재 퍼널의 최대 병목(발급 후 55.4% 미사용)이 "기술 허들"에서 기인하며, 원클릭 연동으로 해소되면 퍼널 구조가 바뀐다. 동시에 클로드 종속도 해소되어 타겟 고객 풀이 넓어진다.

### 그랜드 오픈 후에도 잔존할 과제

1. **BASIC 30크레딧 가치 전달** — 기술 허들 해소 후에도 무료 유저의 가치 체감은 별도 설계 필요
2. **광고 타겟 전환** — 인지 목적에서 전환 목적으로 바꿀 때, 크리에이티브·타겟·KPI 전면 재설계 필요
3. **대기업 보안 정책** — GPT 앱/커넥터로도 해결 안 되는 구조적 제약
4. **"내장 AI 에이전트" 수요** — MCP/외부 앱 방식과 별개로 모바일인덱스 자체 AI 기능 수요 존재
